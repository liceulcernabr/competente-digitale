# Competențe digitale – pregătire Proba D (clasa a XII-a)

Site static pentru pregătirea probei de evaluare a competențelor digitale (bacalaureat).
Liceul Teoretic „Panait Cerna” Brăila – prof. Aura Ion.

## Publicare pe GitHub Pages
1. Creați un repository nou (de ex. `competente-digitale`) în contul `liceulcernabr`.
2. Încărcați tot conținutul acestui folder (index.html, assets/, resurse/).
3. Settings → Pages → Branch: `main`, folder `/ (root)` → Save.
4. Site-ul va fi disponibil la `https://liceulcernabr.github.io/competente-digitale/`.

## Structură
- `index.html` – pagina principală
- `assets/variants.js` – variantele de examen (cerințe, barem, rezolvări)
- `assets/theory.js` – capitolele de teorie
- `assets/questions.js` – întrebări Subiectul II și grile
- `assets/labs.js` – laboratorul Excel (motor de formule) și HTML
- `resurse/` – arhivele cu directorul `examen` pentru fiecare variantă

Pentru a adăuga o variantă nouă, copiați un bloc din `assets/variants.js` și puneți arhiva ei în `resurse/`.
